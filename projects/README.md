# 🏆 Mini Projects

Standalone Python scripts that combine concepts from all lessons. Full walkthroughs with output and screenshots are in **[Lesson 27 — Mini Projects](../lessons/27-mini-projects/README.md)**.

| Script | Description | Run |
|---|---|---|
| [`calculator.py`](calculator.py) | Menu-driven calculator with input validation | `python projects/calculator.py` |
| [`guessing_game.py`](guessing_game.py) | Guess the secret number in 7 tries | `python projects/guessing_game.py` |
| [`todo.py`](todo.py) | To-do list saved to a JSON file | `python projects/todo.py` |
| [`grade_manager.py`](grade_manager.py) | Student grade book with rankings | `python projects/grade_manager.py` |
| [`password_tool.py`](password_tool.py) | Password generator & strength checker | `python projects/password_tool.py` |

> 💡 Tip: in `guessing_game.py`, remove `seed=3` to get a different secret number every game.
