# 🤝 Contributing to Python Beginner Guide

Thank you for helping make this guide better! All kinds of contributions are welcome:

- 🐛 Fix typos, broken links or incorrect output
- 📘 Improve an explanation or add a diagram
- ✍️ Add new exercises (with solutions)
- 💡 Suggest a new lesson or mini project

## How to contribute

1. **Fork** this repository and create a branch:
   ```bash
   git checkout -b improve-lesson-05
   ```
2. Make your changes.
   - Keep each lesson's `README.md`, `lesson.ipynb` and `exercises.ipynb` in sync.
   - **Run** every notebook you change from top to bottom (*Kernel → Restart & Run All*) so the saved outputs are correct.
   - If you change an example's output, update its screenshot in `screenshots/`.
3. Follow the style of the guide:
   - Python 3.10+, standard library only
   - [PEP 8](https://peps.python.org/pep-0008/) naming (`snake_case` variables, `PascalCase` classes)
   - Short, beginner-friendly explanations
4. **Commit** with a clear message and open a **Pull Request** describing what you changed.

## Reporting issues

Open an [issue](https://github.com/MehvishKiani/Python-beginner-guide/issues) with the lesson number, what you expected, and what happened.

Happy coding! 🐍
